# AI Prompt Logs

This directory contains system prompts, few-shot examples, and execution logs for all generative AI interactions in the CIT Campus Scheduling Platform.

## Log Structure
1. `booking_parser.md`: Prompt used for converting unstructured venue requests in English and Hinglish into structured booking JSON.
2. `explainer.md`: Prompt used for explaining scheduling conflicts, soft constraint trade-offs, and booking decisions in plain English.
3. `disruption_assistant.md`: Prompt used by faculty to request schedule changes in natural language.
