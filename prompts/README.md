# AI Prompt Logs

This directory contains system prompts, few-shot examples, and execution logs for all generative AI interactions in the CIT Campus Scheduling Platform.

## Log Files
1. `booking_parser.md`: System prompt & few-shot examples for parsing unstructured English/Hinglish venue booking requests into structured JSON drafts with anti-bypass guard.
2. `decision_explainer.md`: System prompt for generating clear, factual explanations of validator decisions and clash recommendations.
3. `faculty_reschedule.md`: System prompt for faculty emergency leave & room maintenance disruption parsing.
